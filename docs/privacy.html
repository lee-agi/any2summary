Privacy Policy

Last updated: January 2025

Summary: any2summary does not collect, store, or share any personal data. All processing happens locally in your browser, and your API keys are stored only on your device.

Introduction

any2summary is a Chrome extension that helps you summarize web pages, YouTube videos, and articles using AI. This privacy policy explains how the extension handles your data.

Data Collection

We do not collect any personal data. The extension operates entirely within your browser and does not send any data to our servers.

Data Storage

The following data is stored locally in your browser using Chrome's storage API:

  • API Configuration: Your Azure OpenAI or compatible API endpoint, API key, and deployment settings. These are stored securely in your browser's local storage and are never transmitted to any third party.
  • Extension Settings: Your preferences such as cache settings, auto-save options, and local server configuration.
  • Cached Summaries: If caching is enabled, summaries are temporarily stored locally to avoid redundant API calls.

Data Processing

When you use the extension to summarize content:

  • The URL and page content of the active tab are read by the extension.
  • This content is sent directly from your browser to your configured AI API endpoint (Azure OpenAI or compatible service) to generate summaries.
  • The extension does not route this data through any intermediate servers.
  • Generated summaries can be saved locally to your device if you enable the auto-save feature.

Third-Party Services

The extension connects to the AI API endpoint you configure (e.g., Azure OpenAI). Please review the privacy policy of your chosen AI service provider:

  • Microsoft Privacy Statement (for Azure OpenAI)
  • OpenAI Privacy Policy

Permissions

The extension requires the following permissions:

  • activeTab: To read the URL and content of the current tab when you activate the extension.
  • storage: To save your settings and API configuration locally.
  • scripting: To extract content from web pages for summarization.
  • notifications: To notify you when summarization is complete.
  • downloads: To save summaries as Markdown files to your device.
  • host_permissions (all_urls): To access content from any website you want to summarize.

Data Sharing

We do not share any data with third parties. Your data flows directly between your browser and your configured AI API endpoint. We have no access to your API keys, browsing history, or generated summaries.

Data Security

  • API keys are stored using Chrome's secure storage API.
  • All communication with AI APIs uses HTTPS encryption.
  • No data is transmitted to the extension developer or any third party.

Your Rights

Since all data is stored locally on your device, you have full control:

  • You can view and modify your settings at any time through the extension's options page.
  • You can clear all stored data by removing the extension.
  • You can export or delete saved summaries from your downloads folder.

Children's Privacy

This extension is not directed at children under the age of 13 and does not knowingly collect any personal information from children.

Changes to This Policy

We may update this privacy policy from time to time. Any changes will be posted on this page with an updated revision date.

Contact

If you have any questions about this privacy policy, please open an issue on our GitHub repository.
